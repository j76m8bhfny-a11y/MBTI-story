---
1. 产品定义 (Product Definition)
1.1 核心价值
一款以“人生模拟”为外壳的沉浸式 MBTI 测试工具。
- 差异化: 用 60 个本土化生活场景 替代抽象题目；用 几何韵律刻度尺 替代传统评分，消除用户被审视感。
- 技术特色: 纯前端架构，无后端数据库，利用 URL Payload 实现完整的社交裂变。
1.2 关键业务指标 (KPI)
1. 完读率: > 80% (用户从 Q1 坚持到 Q60)。
2. 裂变率: > 30% (访客点击“我也要测”的转化)。

---
2. 核心用户路径 (User Flow)
设计原则：先体验心流，后获取授权，最后社交闭环。
1. 冷启动: 检查本地存档 -> (无) 静默开始 (默认“神秘人”身份，无门槛)。
2. 心流体验: 连续答题 (Q1-Q60) -> 顶部无阻塞提示进度 -> 资源后台静默预载。
3. 结果生成: 算分结束 -> 展示结果文案 -> 点击“生成人生档案”。
4. 高意愿授权: 触发隐私协议 -> 获取头像昵称 -> Canvas 绘图。
5. 社交闭环:
  - 用户 A 分享海报/链接 (携带加密结果参数)。
  - 用户 B 点击 -> 本地解析 URL -> 渲染 UserA 的结果页 -> 点击“我也要测”。

3.1.1 核心交互：水平磁吸刻度尺 (Geometric Magnetic Ruler)
- 组件形态: 底部横向滑动尺，中心固定指针。
- 视觉规范 (去数字化):
  - 严禁出现数字 (-3, +3 等)。
  - 几何韵律:
    - 中心 (0): 空心圆环 (○) 或 菱形框，暗示“中立/原点”。
    - 一级 (±1): 小实心点 (•)。
    - 二级 (±2): 中实心点 (●)。
    - 三级 (±3): 大实心点 (⬤) 或 星形，暗示“强烈/极致”。
  - 对称性: 左右符号完全一致，仅通过位置区分倾向。
- 操作逻辑:
  - 滑动: 左右拖动尺子。
  - 磁吸: 松手后自动吸附到最近的“图形点”，严禁悬停在中间。
  - 点选: 点击尺子左/右侧，自动滑向下一格。
- 反馈机制:
  - 震动: 经过刻度触发 uni.vibrateShort。
  - 延迟刷新: 滑动中上方文字不刷新；吸附完成后，文字淡入刷新 (防眼花)。
3.1.2 界面布局：防抖动文本容器
- 固定高度: 容器高度固定 (建议 200rpx)，容纳 3 行文字。
- 动画: 文字切换增加 200ms 淡入淡出。
3.1.3 阶段提示
- Top Notification: 使用顶部下滑通知条（“🎉 解锁青年阶段”），严禁使用原生 Toast。
3.2 模块二：结果结算与授权 (Result & Auth)
- 优先级: P0
- 合规流程:
  1. 点击“生成档案”。
  2. 检查 __usePrivacyCheck__。若未授权，弹出微信官方隐私弹窗。
  3. 用户同意后，调用 chooseAvatar。
  4. 数据持久化: 必须将头像临时路径转存为永久本地文件 (见 7.1)。
3.3 模块三：海报合成与容错 (Robust Canvas)
- 机制: Promise.race 竞态容错。
  - Plan A (高清): 4秒内下载底图+头像 -> 合成精美海报。
  - Plan B (降级): 超时/报错 -> 生成“纯色背景 + 大字文案 + 本地小程序码”。
3.4 模块四：社交裂变 (Social - URL Payload)
- 分享给朋友 (Sender):
  - 标题: “@昵称 的真实人生居然是...”。
  - URL 参数: /pages/index?mode=guest&mbti=ENFP&nick=EncodedName。
  - 注意: nick 需截取前 10 字符并 encodeURIComponent。
- 访客模式 (Receiver):
  - 逻辑: onLoad 检测到 mode=guest。
  - 渲染: 本地匹配 bg_enfp.png + 解码显示昵称。
  - 转化: 底部悬浮大按钮 “我也要重启人生” -> 清除参数，重载首页。

4. 技术与架构规范 (Technical Architecture)
4.1 目录与分包
- Main Package: 核心 JS, 题目 JSON, Q1-Q5 图片, 本地二维码, 刻度尺组件, 隐私协议组件。

4.2 数据结构 (JSON Optimization)
- 虽然 UI 去除了数字，但底层逻辑仍需映射分数。
- 映射表:
  - Index 0 (大点/左) -> -3分
  - Index 3 (空心/中) -> 0分
  - Index 6 (大点/右) -> +3分
4.3 安全区域适配 (Safe Area)
- 结果底图: 750x1334px。
  - Top: 留白 88px (避让刘海)。
  - Bottom: 留白 68px (避让 Home Indicator)。
  - 警告: 关键文字严禁进入红区。

7. 🛠️ 开发红线与最终修正补丁 (Critical Patches)
⚠️ 警告: 以下 4 点为技术红线，违反将导致严重 Bug 或审核被拒。
1. 数据持久化 (Avatar Persistence):
  - chooseAvatar 返回的是临时文件。必须调用 wx.getFileSystemManager().saveFile 转存为永久文件后，再存入 Storage。否则隔天头像消失。
2. 交互优化 (No Native Toast):
  - 严禁使用 wx.showToast 进行阶段提示。必须封装顶部下滑通知条 (Top Notification)。
3. 逻辑防御 (Debounce & Lock):
  - “确定”按钮增加 500ms 节流。
  - 在刻度尺滑动/吸附动画播放期间，按钮必须 Disabled (防止计分错乱)。
4. 架构防御 (Guest Mode Safety):
  - 访客模式下，若 try-catch 解析 URL 参数失败（如乱码），强制重定向到首页开启新测试，防止白屏。
