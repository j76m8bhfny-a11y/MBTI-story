# 场景图片目录

此目录用于存放 MBTI 测试题目的场景配图。

## 图片命名规范

图片文件名应遵循以下格式：`q{题目序号}_{场景描述}.jpg`

例如：
- `q1_school_playground.jpg` - 第1题：校园操场
- `q2_art_class.jpg` - 第2题：美术课
- `q3_friendship.jpg` - 第3题：友情
- ...

## 图片尺寸建议

- **推荐尺寸**: 750 × 424 像素（16:9 比例）
- **最小尺寸**: 750 × 320 像素
- **格式**: JPG 或 PNG
- **文件大小**: 建议每张图片不超过 200KB

## 场景标签分类

根据题目内容，图片应体现以下场景标签：

- **校园**: 学校、教室、操场、宿舍等
- **家庭**: 家居、装修、亲子、理财等
- **友情**: 朋友、同学、社交等
- **爱情**: 恋爱、伴侣、表白等
- **职场**: 工作、面试、加班、团建等
- **社交**: 聚会、旅行、活动等

## 默认占位图

在 `miniprogram/assets/images/` 目录下应有一个 `default_cover.png` 作为默认占位图。
